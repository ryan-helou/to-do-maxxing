**One calendar and one set of rules, so everything I have to do lives in one place.**

I run my whole schedule from a single calendar. Anything with a date goes on it, and anything without a date goes on a short task list. Every tool I use follows the same written rules, so nothing gets double-booked, lost or left half-done.

Events are sorted into five areas (content, training, tasks, school and life), each with its own tag and colour, so I can see what kind of day I have at a glance. Finished tasks come off the list straight away, and asking "what do I have today?" always gives a clean, time-ordered answer.

The full set of rules is in [schedule-protocol.md](schedule-protocol.md).
